{% load vantage i18n %}{% comment %} The sidebar editor. A second form on the settings page, not a fourth section of the first one: a form cannot nest, and Save here must not carry every branding field along with it. Everything is an ordinary control. Order is a number box per row; moving an item to another group is a select. Both are the accessible, scriptless mechanism *and* what the server reads, so the drag handler that rewrites them can never disagree with the page about what order things are in. Delete vantage-settings.js and this screen still reorders, regroups, renames, hides and adds links — it just does it with the keyboard. Save comes before Reset in the footer on purpose. Pressing Enter in a text box submits the form's *first* submit button, so a destructive control placed above the fields is a data-loss bug waiting for somebody in a hurry. {% endcomment %} {% translate "No heading" as untitled_group %}
