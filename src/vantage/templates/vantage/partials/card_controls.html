{% load vantage i18n %}{% comment %} The strip of controls above one card while the dashboard is being arranged. Everything here works with scripting off, and the number box is the reason. Position is a number you can type; width is a select; removing a card is unticking a box. vantage-dashboard.js hides the number behind a drag handle and a pair of ↑/↓ buttons, but it only ever *rewrites* the number, so the drag and the form can never disagree about the order that will be saved. The tick box is named `keep` rather than `remove` on purpose: an unticked checkbox sends nothing, so "keep" has to be the affirmative or a card would vanish whenever the browser declined to send the field. {% endcomment %}
