{% load static vantage %} {% comment %} The grid's own toolbar: density, column visibility and order, the keyboard preference and the cheat sheet. Everything here is a preference — "how the rows look" — and none of it touches "which rows", which stays in the query string. That is the line drawn in the list-page decisions doc, and it is why nothing in this file submits a form: the URL is not allowed to grow a `columns=` parameter. The stylesheet and the script load from here rather than from the base template because a page with no grid on it should pay for neither, and because the partial is then the whole feature — the same arrangement the command palette uses. {% endcomment %}
{% comment %} Two buttons rather than a select: aria-pressed states the current density without a label, and the pair is one tab stop's worth of typing to reach. {% endcomment %}

{% comment %} WCAG 2.1.4 asks for three things and this is the second: a way to turn the single-character shortcuts off. Gmail ships shortcuts off by default for this reason; here they are on, because scoping them to the grid (the first thing) means they cannot fire while you are typing anywhere else. {% endcomment %}
