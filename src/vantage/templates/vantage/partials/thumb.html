Two shapes and no third: a real when a derived thumbnail exists, and a named chip with an icon when one does not — because Pillow is absent, because the file is a PDF, or because the image could not be decoded. There is deliberately no "broken image" state; a chip is a worse picture and a better answer. width and height are always written out. They are the CSS box, not the bitmap, and they are what reserves the row's height before a single byte of image arrives — without them a list of fifty lazy-loaded thumbnails reflows the page fifty times as it settles.
