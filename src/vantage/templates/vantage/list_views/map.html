An inline SVG plot, server-rendered and dependency-free: no map library, no script, and — unless the owner set VANTAGE["MAP_TILE_URL"] — nothing fetched from anywhere. Every point is a link to its record. The plot is a picture for sighted pointer users; the list under it is the same data for everybody else, and it is where the OpenStreetMap links live. A point on a plot is a poor keyboard target and a worse screen-reader one, so the plot's points stay out of the tab order and the list carries the real controls. {% endcomment %}
