{% load static i18n %}{% comment %} The Kanban board. One column per value of the board's field, each a list of cards. Moving a card has two ways in, and neither is the only one. Drag and drop for the pointer, and a "Move to…" menu on every card for the keyboard, for touch screens where HTML5 drag never fires, and for anybody who prefers to say where a card goes rather than carry it there. The menu is a real form posting to the same endpoint, so it works with JavaScript switched off; vantage-listviews.js upgrades it to a fetch. Nothing about moving is drawn unless the server already said this person may move cards — model-level change permission and a field the change form would let them write. Each move is still checked again, per object, on the way in. {% endcomment %}
