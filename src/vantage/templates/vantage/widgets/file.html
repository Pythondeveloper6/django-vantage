{% load static vantage i18n %}{% comment %} The upload control, for any file field. Progressive by construction. What a browser with JavaScript disabled renders is a labelled and Django's own clear checkbox — a complete, working upload control. Everything else here is inert markup that upload.js finds by its data- attributes; if the script never runs, nothing below is missing, only quieter. The clear checkbox is emitted only when the field is not required, which is Django's reading of blank=True on the model.
